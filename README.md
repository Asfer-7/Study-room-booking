Study room booking 

A full stack web application to book and manage study rooms.

Tech stack

Frontend - React.js
Backend  - Node.js
Database - postgreSQL

Features 

VIew avaliable rooms
Book a room by name, date, and time slot
Cancel existing bookings
Duplicate slot prevention

How to run/access

Backend - in terminal
cd backend
npm install
npm run dev

Frontend - in terminal
cd frontend
npm install
npm start

Additional info

The backend runs on port 5000
The frontend runs on port 3000
PostgreSQL should be running locally
